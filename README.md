# 💼 Business Card Generator

A modern and responsive Business Card Generator built using React and Tailwind CSS.
Users can enter their details, preview their card live, upload a profile/logo image, choose themes, and download the business card as PDF or PNG.

---

# 🚀 Live Demo

🔗 https://business-card-generator-delta.vercel.app

---

# ✨ Features

- Live business card preview
- Upload profile/logo image
- Multiple card themes
- Download as PDF
- Download as PNG
- Responsive design
- Clean and simple user experience

---

# 🛠️ Tech Stack

Frontend

- React.js
- Vite
- Tailwind CSS

Libraries Used

- html2canvas
- jsPDF
- react-icons

Deployment

- Vercel

# ⚙️ Installation & Setup

1️⃣ Clone Repository

git clone https://github.com/YOUR_USERNAME/Business-Card-Generator.git

---

2️⃣ Open Project Folder

cd Business-Card-Generator

---

3️⃣ Install Dependencies

npm install

---

4️⃣ Start Development Server

npm run dev

---
